## What this entry does

`main.ts` writes exactly one line — a single office joke, 100 characters — to `/output/entry.txt`. No dependencies, no network access, fully deterministic: the same line on every run.

## How to run

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22 or later. The program creates `/output` if it does not exist.
